# 💳 Chat Defense - Бот продаж и подписок

Бот-витрина для продажи подписок на систему защиты чатов **Chat Defense** (`@Chat_defense_bot`).

## 💰 Тарифная сетка

### 1. Тариф «Обычный» (Standard)
* **1 месяц:** 149 руб (75 ⭐)
* **3 месяца:** 399 руб (200 ⭐)
* **9 месяцев:** 1099 руб (550 ⭐)
* **12 месяцев:** 1390 руб (700 ⭐)

### 2. Тариф «PRO» (Максимум возможностей)
* **1 месяц:** 239 руб (120 ⭐)

## 🚀 Возможности бота:
- 💳 Каталог тарифов и периодов (1, 3, 9, 12 месяцев).
- ⭐ Прием платежей в Telegram Stars в 1 клик.
- 💳 Оплата по СБП и картой со связью с поддержкой (@Bonzayka).
- 🤖 Автоматический запуск персонального бота клиента после оплаты через `manager.py`.
- 📋 Личный кабинет покупателя: просмотр активных подписок и привязанных ботов.
- 📜 Оферта и политика конфиденциальности для согласования с платежными системами.
- ⚙️ Админка: статистика, команда ручной выдачи `/give_sub me 12 pro` или вход по `/admin 7116116919`.

## 📦 Запуск:
```bash
python main.py
```
или запуск файла `run.bat`.
