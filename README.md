# 💳 Bonzayka Defense — Бот продаж и подписок

Бот-витрина для продажи подписок на облачную систему защиты чатов **Bonzayka Defense** (`@bonzayka_defense_bot`).

## 💰 Тарифная сетка

### 1. Тариф «Обычный» (Standard)
* **1 месяц:** 149 ₽ (75 ⭐)
* **3 месяца:** 399 ₽ (200 ⭐)
* **9 месяцев:** 1 099 ₽ (550 ⭐)
* **12 месяцев:** 1 390 ₽ (700 ⭐)

### 2. Тариф «PRO» (Максимум + ИИ)
* **1 месяц:** 239 ₽ (120 ⭐)
* **3 месяца:** 649 ₽ (330 ⭐)
* **9 месяцев:** 1 790 ₽ (900 ⭐)
* **12 месяцев:** 2 290 ₽ (1150 ⭐)

---

## 🚀 Возможности бота:
- 💳 **Каталог тарифов и периодов** (1, 3, 9, 12 месяцев).
- ⭐ **Приём платежей в Telegram Stars** в 1 клик прямо внутри Telegram.
- 💳 **Оплата по СБП / картой РФ** со связью с поддержкой (`@Bonzayka`).
- 🤖 **Автоматический запуск персонального бота клиента:** после оплаты клиент отправляет токен из @BotFather, и система мгновенно поднимает изолированного бота через `manager.py`.
- 📋 **Личный кабинет покупателя:** просмотр активных подписок, срока окончания и привязанных ботов.
- 📜 **Оферта и политика конфиденциальности:** полная юридическая база для согласования с платёжными агрегаторами.
- ⚙️ **Админ-панель:** `/admin`, статистика и команда ручной активации `/give_sub <user_id> <months> <standard|pro>`.

## 📦 Запуск:
```bash
python main.py
```
или запуск файла `run.bat`.
